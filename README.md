# HLUMA-MBEYU-SIKHUBONE-
Hluma Mbewu Sikubone (HMS) is a faith-based NGO in George, South Africa, dedicated to empowering teenage girls. Meaning "Grow, Seed, So We Can See You," HMS guides youth to #BeRootedInChrist. Through mentorship, school outreach, and conferences, we provide a safe space to combat peer pressure, build resilience, and develop purposeful young leaders.
